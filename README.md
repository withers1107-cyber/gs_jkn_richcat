ゲームルールとシステム

• リズム×ジャンケンバトル: 画面上部にある対戦相手（ボス猫）のジャンケンの手を見て、下の4つのレーン（← ↓ ↑ →）から「勝てる手」が配置されたレーンを瞬時に見つけ出し、流れてくる猫をタイミングよくキャッチします。
• ランダムシャッフルと詰み防止: 4つのレーンの手は一定時間ごと、またはジャンケンに勝利するたびにランダムで入れ替わります。必ずボス猫に勝てる手が1つ以上含まれる設計になっているため、理不尽な盤面になりません。
• 勝利条件: スコアが 10,000点 に到達するとゲームクリア（勝利画面）となり、リトライボタンから何度でも再挑戦できます。
